# team/: samenwerking tussen de AI-chats

Drie rollen, één eigenaar per bestand. Luc keurt goed; niemand voert iets uit zonder zijn akkoord.

| Rol | Doet | Schrijft in |
|---|---|---|
| Marketing & financials | Plannen: prijs, licenties, verkoopkanaal, kosten, weekplannen | `team/PLAN-<onderwerp>.md` |
| Socials | Uitvoeren: content, Metricool, ClickUp-links, mail/Brevo | `social/STATUS.md`, `team/INBOX-bouwer.md` |
| Bouwer (Codex) | App en site bouwen (MixPrep-repo) | MixPrep-repo (`docs/TODO.md`), `team/INBOX-socials.md` |

Regels
- Eén plan per onderwerp in `PLAN-*.md`: doel, keuze, stappen, wie voert uit, akkoord van Luc (ja/nee), status.
- Vragen aan een andere rol: zet ze in de INBOX van die rol (datum, van wie, vraag). Beantwoorden = regel eronder zetten, niet verwijderen.
- Alleen bevestigde functies in publieke claims: automatisch kleuren, benoemen/ordenen, routing (aux), Strip Silence. Bij aantallen "tracks", bevestigd aantal 69.
- Chats kunnen niet pushen; Luc klikt "Push origin" in GitHub Desktop.

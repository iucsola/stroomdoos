# stroomdoos.com

Promo site for MixPrep by Stroomdoos. Plain static files, served by GitHub Pages on stroomdoos.com.

- `index.html`: the whole page (styles inline).
- `shot-*.jpg`: app screenshots from MixPrep `docs/design/current/`.
- `mixprep-demo.mp4`, `mixprep-poster.jpg`: background video and its still.
- `CNAME`: the custom domain. Do not remove.

Updating: edit `index.html` and commit to `main`. Pages redeploys in about a minute.

## Brand assets for Claude

The selected Stroomdoos S-wordmark and orange power-strip assets are in
[`assets/brand/`](assets/brand/README.md), with usage notes and a file manifest.
Stroomdoos is the developer brand; MixPrep remains the product name.

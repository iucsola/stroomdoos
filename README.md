# stroomdoos.com

Promo site for Primer by Stroomdoos. Plain static files, served by GitHub Pages on stroomdoos.com.

- `index.html`: the home page (styles inline); `site.css` holds the shared styles.
- `shot-*.jpg`: app screenshots from Primer `docs/design/current/`.
- `stroomdoos-woordmerk.svg`, `stroomdoos-stekkerdoos.svg`, `favicon*`, `apple-touch-icon.png`: the Stroomdoos logos.
- `primer-icon.svg`, `primer-icon.png`: the Primer app icon.
- `CNAME`: the custom domain. Do not remove.

Updating: edit the pages and commit to `main`. Pages redeploys in about a minute.

Stroomdoos is the developer brand; Primer is the app. The logo sources are not in this public repo.
